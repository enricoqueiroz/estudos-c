# Estudos em C

Exercícios e listas feitas durante a disciplina de Programação
no IFSP Piracicaba, organizados por tema.

## Temas
- `ponteiros/` — manipulação de ponteiros e passagem por referência
- `structs/` — structs e registros
- `arquivos/` — leitura e escrita em arquivo
- `recursao/` — funções recursivas
- `vetores/` — vetores e funções sobre vetores
- `diversos/` — exercícios gerais (laços, strings, lógica)
